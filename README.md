# 🐾 Aplicación de Veterinaria Full Stack

Esta es una aplicación web de veterinaria full stack desarrollada con Java y Spring Boot en el backend, y HTML, CSS y JavaScript en el frontend.
Incluye funcionalidades de inicio de sesión (login) y un dashboard para la gestión de usuarios, además de testing con JUnit para garantizar la calidad del código.

🚀 Tecnologías principales
🖥️ Backend

Java 8

Spring Boot (para la lógica de negocio y APIs REST)

Spring Security (para autenticación y autorización)

JUnit 5 (para pruebas unitarias)

Maven (gestión de dependencias)

💻 Frontend

HTML5

CSS3

JavaScript (ES6+)

🗄️ Base de datos

MySQL (configurable)
